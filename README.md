# CodeAlpha Basic Chatbot

## Description

This is a simple rule-based chatbot developed using Python.

The chatbot responds to predefined user inputs.

## Features

- Responds to "hello"
- Responds to "how are you"
- Responds to "bye"
- Ends the conversation when the user enters "bye"
- Handles unknown messages

## Technologies Used

- Python

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python main.py
